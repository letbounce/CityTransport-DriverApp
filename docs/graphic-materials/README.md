## Рекомендований порядок у звіті

**Розділ «Графічні матеріали»** (після джерел, перед додатками або навпаки — як у змісті кафедри):

1. Г.1 → Г.10 (сценарій водія)  
2. Г.11 (підтвердження в MongoDB)

**Додатки:** А (код), Б (PDF) — після «Переліку джерел» у Word.

## Вставка в Word

1. Розділ **«Графічні матеріали»** — окрема сторінка-заголовок, далі рис. Г.1–Г.5 (ширина ~14–16 см).  
2. Під кожним рисунком — підпис (стиль «Підпис»).  
3. У тексті п. 3.4 посилатися: «…на рисунку Г.5 підтверджено збереження waybill зі статусом completed».
